Voice Agent System Architecture

Frontend Services
TIER 1 • CLIENT PRESENTATION
Voice Studio Web Interface
HTML5 / Vanilla CSS
Single-page control studio for agent orchestration and call management.
Studio Dashboard: Real-time call logs & metrics
Agent Configurator: Prompts, Voice, LLM selector
Telephony Tab: 1:1 phone routing & dial dispatch
Client Audio Engine
Web Audio API / PCM
In-browser voice capture, buffer streaming, and audio playback queue.
Audio Input Stream: 48kHz mic capture & 16kHz resample
Browser VAD: Dynamic energy voice activity detection
Duplex Audio Buffer: Low-latency streamed voice return
Note: Full-duplex audio stream via WebSocket with client-side VAD barge-in.
Backend Services
TIER 2 • APPLICATION & SPEECH CORE
FastAPI Application Core
FastAPI / Uvicorn
REST gateway, multi-user authentication, and agent policy execution.
Auth & RBAC: Session tokens & role permissions
Tool Registry: Function calling & booking capture
Safety Guardrails: PII masking & calendar validation
Telephony & Speech Loop
WebSocket / Audioop
Bi-directional phone audio transcoding, transcription, and TTS synthesis.
Audio Transcoder: μ-law 8kHz ↔ 16kHz PCM linear
Speech-to-Text (STT): Faster-Whisper CUDA / Groq
Text-to-Speech (TTS): Offline pyttsx3 & Edge-TTS
Note: Real-time barge-in interruption and dynamic context injection via BM25 retrieval.
Data Layer
TIER 3 • PERSISTENCE & INDEXING
SQLite Relational Database
SQLite (agents.db / WAL)
ACID persistent data storage for agents, transcripts, and routing.
Entities: agents, users, agent_members
Call Journal: calls (transcripts, turns, duration)
Routing & Booking: twilio_phone_routes (1:1), bookings
BM25 Retrieval & Outbox Store
BM25 Index / Outbox
Vector-like lexical retrieval index and reliable external event queue.
Inverted Index: Per-agent cached token index
Chunk Store: 700-char overlapping knowledge chunks
Outbox Queue: Reliable webhook delivery & retry
Note: Strict unique constraint guarantees no two agents can share duplicate phone numbers.
Integrations & External
TIER 4 • TELEPHONY & CLOUD APIS
Twilio Voice Telephony
Twilio REST / TwiML
Global telecom carrier gateway and media stream streaming.
Inbound Webhook: TwiML <Connect><Stream>
Media WebSocket: 20ms bidirectional phone stream
Outbound Dial: REST calls.create & status callback
External LLMs & Productivity
Ollama / Groq / Google
Language intelligence providers and automated business integrations.
LLM Router: Ollama (local GPU) / Groq / Gemini
Google Sync: Google Calendar & Sheets API
Tunnel Gateway: ngrok HTTPS/WSS public ingress
Note: Public reverse-tunnel gateway via ngrok forwards secure external PSTN callbacks.
