Frontend Services Tier 1 • Client Presentation
Voice Studio Web UI HTML5 / CSS / ES6
Single-page responsive dashboard for agent setup, testing, and call logs.
Dashboard: Live metrics & history
Agent Editor: System prompt & tools
Telephony Tab: 1:1 phone routing
Client Audio Engine Web Audio API
Browser-side mic stream capture, energy VAD, and playback queue.
Capture: 48kHz mic to 16kHz PCM
Browser VAD: Audio activity trigger
Buffer Queue: Duplex voice playback
Note: Client operates over low-latency duplex WebSocket channel with barge-in support.
Backend Services Tier 2 • Application & Speech Core
FastAPI Application Core FastAPI / Uvicorn
REST API gateway, session auth, RBAC policies, and guardrails.
Auth & RBAC: Session tokens & roles
Tool Registry: Function calling tools
Guardrails: PII masking & calendar check
Telephony & Speech Loop Audioop / Whisper
Bi-directional μ-law transcoding, STT transcription, and TTS speech synthesis.
Transcoding: μ-law 8k ↔ 16k PCM
Whisper STT: CUDA Faster-Whisper
TTS Synthesis: Offline pyttsx3 / Edge
Note: Unified voice engine shared by browser and PSTN calls.
Data Layer Tier 3 • Persistence & Indexing
SQLite Relational Database SQLite (WAL Mode)
ACID transaction store for agents, users, call journals, and routing.
Entities: agents, users, members
Call Store: calls (transcripts, turns)
Routing: 1:1 twilio_phone_routes
BM25 Retrieval & Outbox BM25 / Outbox Queue
In-memory lexical RAG retrieval index and reliable delivery queue.
Inverted Index: Per-agent token index
Chunks: 700-char overlapping text
Outbox: Transactional webhook sync
Note: Strict unique constraint prevents multiple agents sharing the same phone route.
